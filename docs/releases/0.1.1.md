# EQxEar 0.1.1

This release addresses the Arch packaging review of 0.1.0.

- Background service and audio-child startup resolve the application path explicitly, including with `PYTHONSAFEPATH=1`.
- Packages include Python bytecode with installed source paths rather than temporary build paths.
- Version checks and release-note selection support future version bumps.
- The Arch recipe declares its icon-theme dependency and prints upgrade/removal guidance without stopping user audio or deleting presets.
- Package checks include `namcap` and upgrade/removal during isolated playback.

The published 0.1.0 archive is unchanged. Quit the background service and reopen the app after installing an update.
