# EQxEar 0.1.0

The first versioned release packages EQxEar for x86_64 Arch Linux and Omarchy. Build instructions are in [Arch packaging](../arch-packaging.md).

- Live stereo system EQ through PipeWire, with eight parametric bell or shelf filters, graph dragging, scroll-wheel Q adjustment and a logarithmic preamp fader.
- Preset save, recall, replacement and deletion; import EQ by Ear JSON, EQxEar JSON or PEQ text for review before applying.
- Peak normalization follows the active DSP sample rate. Optional two-edge tone tuning and a collapsible spectrum analyzer support tuning by ear.
- The Arch package installs an `eqxear` command, desktop launcher and original icon, with native DSP and FFT libraries compiled during the build.
- Installed-package checks exercise GTK, live audio, the background service and spectrum capture without a compiler. Package removal retains user presets.

The source archive is `eqxear-0.1.0.tar.gz`; the release includes `SHA256SUMS`, and `packaging/arch/PKGBUILD` records the same source checksum. The recipe is available on GitHub and has not yet been submitted to the AUR.

Before switching from a checkout or upgrading, choose **Quit background service** and close the window. If you previously used `./install-launcher`, remove its per-user desktop entry when switching to the package, as described in the packaging instructions. Presets and layouts keep their existing storage locations.

EQxEar is inspired by DMS's [video](https://youtu.be/WIWHINQ5lV8), [EQ by Ear utility](https://eqbyear.com/) and [upstream repository](https://github.com/DMS3tv/eqbyear). It is an independent Apache-2.0 implementation.
